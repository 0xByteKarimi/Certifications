## 📚 What I Learned

This professional certificate consists of **6 courses**, each covering a distinct domain of IT support. Below is a breakdown of the modules, key concepts, and hands-on skills gained in each.

---

### 🧱 Course 1: Technical Support Fundamentals

An introduction to the world of IT support — covering hardware, software, networking, and the human side of helping users.

**Key Concepts**
- Binary code, logic gates, and how computers process data
- Computer hardware components (CPU, RAM, storage, motherboards, peripherals)
- Operating system basics (Windows, Linux, macOS)
- Software installation, updates, and troubleshooting
- Networking fundamentals (IP, DNS, DHCP, NAT)
- Customer service and ticketing systems
- Interviewing techniques and troubleshooting methodologies

**Hands-On Skills Gained**
- Assemble and disassemble a computer
- Install and configure an operating system from scratch
- Write basic troubleshooting documentation
- Use ticketing systems to track and resolve issues

**Tools/Technologies Covered**
- Windows, Linux, macOS
- BIOS/UEFI
- Ticketing systems (Jira, Zendesk basics)
- Command-line basics

---

### 🌐 Course 2: The Bits and Bytes of Computer Networking

A deep dive into how data moves across networks — from local LANs to the global internet.

**Key Concepts**
- OSI and TCP/IP models
- IP addressing, subnetting, and CIDR notation
- DNS, DHCP, NAT, and ARP
- Routing and switching fundamentals
- Wireless networking (802.11 standards, WPA2/WPA3)
- Network troubleshooting tools (ping, traceroute, nslookup, netstat)
- VPNs, firewalls, and network security basics
- Cloud computing and virtual networking

**Hands-On Skills Gained**
- Subnet a network and assign IP addresses
- Configure a home/office router and Wi-Fi
- Diagnose network issues using command-line tools
- Explain data flow across the internet end-to-end

**Tools/Technologies Covered**
- Wireshark
- `ping`, `traceroute`, `nslookup`, `ipconfig`/`ifconfig`, `netstat`
- TCP/IP stack
- DNS/DHCP services

---

### 💻 Course 3: Operating Systems and You: Becoming a Power User

Hands-on mastery of Windows and Linux from a power-user and support perspective.

**Key Concepts**
- File systems (NTFS, ext4, FAT32) and permissions
- User and group management
- Process management and system monitoring
- Package management (apt, yum, MSI)
- Bash and PowerShell scripting fundamentals
- Disk partitioning, mounting, and file system repair
- Log analysis and system performance tuning

**Hands-On Skills Gained**
- Manage users, groups, and permissions in Windows and Linux
- Write basic Bash and PowerShell scripts for automation
- Diagnose and resolve OS-level performance issues
- Mount and repair file systems

**Tools/Technologies Covered**
- Linux CLI (Bash)
- Windows PowerShell and CMD
- `chmod`, `chown`, `systemctl`, `ps`, `top`
- `Get-Process`, `Get-Service`, `New-LocalUser`

---

### 🖥️ Course 4: System Administration and IT Infrastructure Services

The operational backbone of IT — keeping servers, directories, and infrastructure running reliably.

**Key Concepts**
- Server roles (file, print, web, mail, DNS, DHCP)
- Active Directory and LDAP directory services
- User authentication and authorization (SSO, Kerberos, RADIUS)
- Backup strategies and disaster recovery
- Virtualization and cloud infrastructure
- IT infrastructure planning and documentation
- Change management and ITIL basics

**Hands-On Skills Gained**
- Set up and manage a directory service (Active Directory / OpenLDAP)
- Configure file and print servers
- Design a backup and recovery plan
- Deploy virtual machines and manage infrastructure

**Tools/Technologies Covered**
- Active Directory, LDAP
- Windows Server, Linux servers
- VirtualBox / VMware
- Cloud IaaS platforms (introductory)

---

### 🔐 Course 5: IT Security: Defense Against the Digital Dark Arts

A practical introduction to cybersecurity from a defender's perspective.

**Key Concepts**
- CIA triad (Confidentiality, Integrity, Availability)
- Authentication, authorization, and accounting (AAA)
- Encryption (symmetric, asymmetric, hashing, PKI)
- Network security (firewalls, IDS/IPS, VPNs)
- Malware types and defense strategies
- Social engineering and phishing awareness
- Risk management and security policies
- Incident response basics

**Hands-On Skills Gained**
- Implement encryption and hashing for data protection
- Configure firewalls and VPNs
- Identify and respond to common security threats
- Apply security best practices in IT environments

**Tools/Technologies Covered**
- OpenSSL, GPG
- Firewalls (iptables, Windows Firewall)
- VPNs (OpenVPN basics)
- Password managers and MFA tools

A modern, AI-powered approach to landing an IT role — leveraging AI tools for resumes, interviews, and career strategy.

- Job search automation and tracking

**Hands-On Skills Gained**

- Create a professional online presence
